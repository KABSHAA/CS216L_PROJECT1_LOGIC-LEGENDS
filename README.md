Project Title: Student Record System

Group members: KHADIJA RAFIQUE-45 AYEHSA BASHIR-04 KABSHA ASIM-23

Description: This is a simple console-based Student Record System. It stores student records using a singly linked list. It uses a stack to undo the last deleted student. Linear search is used to search students by ID. Bubble sort is used to sort students by GPA.

Data Structures Used:

Singly Linked List
Stack
Searching Algorithm: Linear Search

Sorting Algorithm: Bubble Sort

Features:

Add Student
Display Students
Search Student
Delete Student
Sort Students by GPA
Undo Last Delete
Show Stack Top
Show Stack Size
Show Time Complexity
Time complexity:

Operation	Time Complexity
| Operation   | Time Complexity |
| ----------- | --------------- |
| Insert      | O(1)            |
| Delete      | O(n)            |
| Search      | O(n)            |
| Bubble Sort | O(n²)           |
| Push        | O(1)            |
| Pop         | O(1)            |
